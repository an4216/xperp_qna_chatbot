Q1	부과마감 전에 조정명세서를 볼 수 없나요?
A1	부과마감 전에는 조정명세서(조정대장)를 확인할 수 없습니다.
T1	#조정명세서 #조정대장

Q2	바우처할인 세대 업로드 어떻게 하나요?
A2	[부과 > 부과처리 > 바우처할인] 메뉴에서 조회 후 '엑셀업로드' 버튼을 클릭하여 업로드할 수 있습니다. 엑셀 편집순서에 맞춰 편집한 후 파일을 올리면 됩니다.
T2	#바우처할인 #바우처엑셀업로드

Q3	안 쓰는 부과항목 이름 변경해서 써도 되나요?
A3	"부과항목 이름을 변경해서 사용해도 되나, 과거에 사용했던 항목의 경우 조회했을 때 변경된 이름으로 조회되니 참고하시면 됩니다."
T3	#부과항목 #부과항목변경 #부과항목수정 #부과항목명

Q4	"고지서에 기재된 공지사항을 변경하고 싶을 때, 어떻게 해야 하나요?"
A4	고지서 공지사항 변경은 [부과 > 부과처리 > 수납계좌/공지사항] 메뉴에서내용을 수정한 후 저장 버튼을 누르면 변경된 내용이 적용됩니다.
T4	#고지서공지사항 #공지사항변경 #수납계좌공지사항

Q5	이미 마감된 고지서에도 변경된 공지사항이 적용되는지 궁금합니다.
A5	"자체 출력을 진행하는 단지의 경우, 고지서 출력 시점에 변경된 공지사항이 적용되며, 실제 출력 전 인쇄 미리보기 기능을 통해 변경 사항이 올바르게 반영되었는지 미리 확인할 수 있습니다.출력 대행일 경우, 마감시점의 데이터로 출력이 진행됐기 때문에에 마감 후 수정한 공지사항의 내용은 적용되지 않습니다."
T5	#마감고지서 #공지사항적용 #자체출력 #미리보기 #출력시점

Q6	"관리비 고지서 사업소, 전출자, 소유자로 인쇄하는 방법은 무엇인가요?"
A6	"관리비 고지서가 사업소, 전출자 등으로 분리 부과된 경우, 인쇄 시 출력구분에서 '입주자'로 설정되어 있는 값을 원하는 구분으로 변경해서 조회 후 인쇄하시면 됩니다."
T6	#관리비고지서 #분리부과 #사업소고지서 #전출자고지서 #소유자고지서

Q7	사업소로 통합 고지된 관리비 내역 중 특정 입주자 고지서만 별도로 인쇄할 수 있는 방법은 무엇인가요?
A7	"원하는 동호를 입력한 후, 출력구분에서 ‘합산동호’를 ‘일반동호’로 변경한 뒤 조회하고 인쇄하시면 됩니다."
T7	#개별인쇄 #부분인쇄 #사업소분리 #입주자별도인쇄

Q8	지난달 한 세대 부과를 잘못했는데 어떻게 하나요?
A8	이미 마감한 월분의 부과데이터를 수정할 수는 없습니다. 이 경우에는 다음월분 부과작업 시 오부과된 금액만큼 별도금액등록으로 금액을 더해주시거나 차감해주시면 됩니다.
T8	#오부과 #부과오류 #금액수정 #별도금액등록

Q9	별도금액등록에서 금액을 빼주려면(차감) 어떻게 해야하나요?
A9	"먼저 ‘행추가’ 버튼을 클릭한 후, 부과 항목을 선택하고 동호수를 입력합니다.그다음 분리구분(입주자, 전출자 등)을 선택하고, 금액을 입력합니다.주의: 계산 방법에 따라 금액 입력 방식이 다릅니다.예를 들어, 원래 부과 금액 50,000원에서 10,000원을 차감해야 하는 경우:덮어쓰기: 차감된 최종 금액인 40,000원을 입력금액빼기: 10,000원 (양수) 입력금액더하기: ?10,000원 (음수) 입력"
T9	#별도금액등록 #금액빼기 #금액차감 #덮어쓰기 #금액더하기 #계산방법

Q10	별도금액등록 후 해당 금액이 정확히 합산되었는지 확인하는 절차는 어떻게 되나요?
A10	"별도금액입력 전, [부과 > 부과처리 > 관리비조회] 메뉴에서 조회하여 기존 금액을 확인합니다. 별도금액을 입력한 후, 다시 관리비 조회에서 금액을 확인하여 정상적으로 반영되었는지 검토할 수 있습니다."
T10	#별도금액등록 #별도금액확인 #금액조회 #관리비조회

Q11	관리비부과처리에 안 쓰는 부과항목을 없애고 싶어요.
A11	"[부과 > 기초정보 > 부과항목등록] 메뉴에서 사용하지 않는 항목의 사용여부를 '사용안함'으로 변경 후 저장하시면 됩니다. 단, 사용안함으로 변경하게 되면 과거 부과했던 데이터 조회 시 해당항목이 조회되지 않으니 참고하시길 바랍니다."
T11	#부과항목 #부과항목사용안함 #부과항목삭제

Q12	고지서 조회 시 특정 동호수 입력 없이 전체 세대를 한 번에 조회할 수 있나요?
A12	"고지서 메뉴에서 전체동호를 조회옵션을 제한한 이유는 서버 과부화로 인해 조회속도가 저하되기 때문입니다. 만약 해당조건으로도 전체동호를 조회하기 원하실 경우, 전산업체에 문의하시면 기능을 오픈해드릴 수 있으니 문의 부탁드립니다."
T12	#고지서 #전체세대조회 #조회속도지연

Q13	"부과마감 시 특정 호실(예: 101호) 하나만 보이는데, 한 세대만 고지서가 출력되는 건가요?"
A13	부과마감 후 출력의뢰시 특정 호실(예: 101호) 하나만 조회되는 이유는 출력의뢰 고지서 샘플(이미지)를 확인하는 용도이기때문에 고지서샘플 확인하고자 하시는 세대를 임의로 동호 지정하여 확인 하신후 출력의뢰 해주셔도 전체세대가 고지서출력됩니다.
T13	#부과마감 #출력의뢰 #샘플확인

Q14	"새로 추가한 부과항목이 고지서에 표시되지 않거나 특정 위치에 표시되는 이유는 무엇이며, 어떻게 조정할 수 있나요?"
A14	"고지서출력환경등록에서 출력하고자 하는 고지서종류에 부과항목의 위치설정이 되어있지 않기때문이며, 출력될 고지서위치 및 설정을 다시 저장한 다음 고지서 인쇄를 해보셔야 합니다."
T14	#고지서 #고지서출력환경등록 #부과항목위치

Q15	사용하지 않는 부과항목을 삭제할 수 있나요?
A15	프로그램에서 부과하여 사용을 했던 부과항목은 과거 부과내역 등 다른 데이터가 저장되어 있기때문에 강제로  삭제처리는 불가능합니다. 다만 현재 미사용 부과항목을 비활성화 처리하여 부과작업시 보이지 않도록 숨김처리로 변경 처리하여 관리해야 합니다.
T15	#부과항목삭제불가 #비활성화

Q16	"전출 처리된 세대가 분리 부과 내역에 표시되지 않는 이유는 무엇이며, 해결 방법은 무엇인가요?"
A16	"분리부과 처리에서 분리부과 수신 이후 전출처리 되었을 경우, 이미 수신된 내역에서 자동으로 추가등록되지 않기때문에, 분리부과 재수신하여 해당세대가 수신되는지 확인해야 합니다. 만약 수기로 수정된 내역이 있으신경우 재수신시 수기로 수정한 부분도 초기화 되기때문에, 해당 조건에는 행추가로 해당세대를 추가 등록하여 분리부과 처리해야 합니다."
T16	#전출처리 #분리부과수신

Q17	신규 부과항목 등록 시 '징수대행' 또는 '누진여부' 설정은 어떻게 적용해야 하나요?
A17	부과항목의 상위그룹인 징수대행은 개별 세대에 부과되는 관리비를 뜻합니다. 누진여부의 경우 중간관리비정산시 누진율 입력이 적용 여부를 뜻합니다.
T17	#신규항목 #누진여부 #징수대행

Q18	부과마감 자동이체세대등록의 마감일은 어떤기준인가요?
A18	부과마감일 기준 5일전까지 부과마감을 처리해야 자동이체 처리가 가능합니다. 5일전 기준은 평일 은행근무일 기준입니다.
T18	#마감일기준 #자동이체등록마감일

Q19	신주차비 부과 시스템에서 주차비 수정 사항이 반영되지 않는 원인과 해결 방안은 무엇인가요?
A19	"신주차비 부과 시스템에서 주차비 수정 사항이 반영되지 않는 원인은, 수정 작업을 완료한 후 해당 메뉴에서 '새로고침' 버튼을 누르지 않아 시스템이 최신 데이터를 재수신하지 못했기 때문입니다. 이 문제를 해결하려면, 주차비 수정 작업 후 해당 메뉴의 오른쪽 상단에 있는 동그라미 화살표 모양의 '새로고침' 버튼을 클릭하여 데이터를 재조회한 다음 주차비 계산을 다시 진행해야 합니다."
T19	#주차비 #주차비부과 #데이터미반영 #새로고침

Q20	특정 세대의 관리비 조정 집계표를 3년치 한 번에 출력할 수 있나요?
A20	"특정 세대의 관리비 조정 집계표는 시스템상 연간 고지 현황으로 제공되므로, 3년치 자료를 한 번에 출력할 수 없고 1년 단위로 조회하여 출력해야 합니다."
T20	#관리비조정집계표 #3년치출력 #연간고지현황 #1년단위조회

Q21	"부과 마감 시 ""관리비 할인 세대가 있습니다""라는 메시지가 뜨며 진행되지 않는 이유는 무엇이며, 어떻게 해결해야 하나요?"
A21	"이 메시지는 기존 부과 처리 이후 관리비 할인 신청이 발생한 세대가 있어, 해당 할인을 적용하기 위해 재처리가 필요함을 의미합니다. 해결을 위해서는 '관리비 부과 처리' 메뉴로 이동하여, 금액 변동이 없는 임의의 한 항목을 '재부과 선택'한 후 '단가 처리'를 진행하시면 부과 마감을 완료할 수 있습니다."
T21	#부과마감오류 #관리비할인 #재부과처리 #단가처리 #관리비부과처리

Q22	이메일 고지서를 전체에게 전송하려면 어떻게 해야 하나요?
A22	"이메일 고지서를 전체에게 전송하려면, 이메일고지서발송 메뉴에서 오른쪽 위쪽에 있는 '일괄 등록' 버튼을 누르고 전체 고지서를 선택하여 저장하면됩니다."
T22	#이메일고지서 #전체전송 #일괄등록 #부과마감 #고지서발송

Q23	특정 세대의 고지서가 조회되지 않고 출력이 되지 않는 이유는 무엇인가요?
A23	"해당 세대가 전자 고지서를 신청했기 때문에 고지서 조회가 어려울 수 있으며, 이 경우 프로그램에서 '종이 고지서 미출력 세대 포함' 항목을 체크하여 조회하면 정상적으로 출력할 수 있습니다."
T23	#고지서조회 #고지서출력 #전자고지서 #종이고지서미출력세대포함

Q24	관리비 고지서가 전체세대 중 일부만 발행된 원인과 해결 방안은 무엇인가요?
A24	"고객이 '분리 합산 부과' 방식을 사용했지만, 주로 '입주자' 합산 설정만 되어 있고 '소유자' 세대들은 개별 부과되거나 합산 설정이 누락되었을 가능성이 높으며, 이를 해결하기 위해서는 '합산 동호 관리' 메뉴에서 입주자와 소유주별 합산 설정을 정확히 확인하고, 발행되지 않은 특정 호실을 파악하여 해당 호실의 부과 방식(입주자/소유자, 개별/합산)을 검토해야 합니다."
T24	#고지서부족 #합산부과 #분리부과 #입주자합산 #소유주개별부과 #합산동호관리 #누락세대확인

Q25	관리비 부과 시 '입주자'와 '소유주'의 구분 및 합산 처리는 어떻게 이루어지나요?
A25	"관리비 부과 시 '입주자'와 '소유주'는 별개의 유형으로 간주되어 서로 합산할 수 없으며, '입주자'는 입주자끼리, '소유주'는 소유주끼리만 '합산 동호 관리' 메뉴에서 통합 고지서 발행을 위한 설정이 가능하므로, 각 유형에 맞는 합산 설정을 통해 중복 고지서 발행 없이 원하는 방식으로 부과할 수 있습니다."
T25	#입주자부과 #소유주부과 #합산구분 #별도합산 #고지서발행기준

A203	"해당 세대가 '부과 마감 등록' 메뉴의 '전자 고지서 신청 리스트'에 등록되어 전자 고지서를 신청한 경우, 종이 고지서로 자동 출력되지 않으므로 고지서가 없는 것이 정상입니다. 따라서 해당 세대에는 고지서를 따로 출력하여 배부하지 않으셔도 됩니다. 다만, 해당 세대의 요청으로 종이 고지서 출력이 필요한 경우에는 '고지서' 메뉴에서 '종이 고지서 미출력 세대 포함' 옵션을 체크한 후 출력할 수 있습니다."
